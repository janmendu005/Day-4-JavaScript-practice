# Day 4 JavaScript Practice

A collection of JavaScript exercises and mini-projects focused on asynchronous programming concepts, API interactions, and practical DOM manipulation. This repository is part of my continuous learning journey in JavaScript and web development.

---

## 📚 Topics Covered

### 1. Async & Await

Files:

* `async.js`
* `await.js`

Concepts practiced:

* Creating asynchronous functions using `async`
* Pausing execution using `await`
* Handling asynchronous operations more cleanly than chained promises
* Improving code readability and maintainability

Key Learning Outcomes:

* Understanding asynchronous execution flow
* Writing cleaner asynchronous JavaScript
* Working with promise-based functions

---

### 2. Fetch API

Files:

* `async-fetch.js`
* `fetch-practice.js`

Concepts practiced:

* Making HTTP requests
* Fetching data from external APIs
* Parsing JSON responses
* Error handling with asynchronous requests
* Combining Fetch API with Async/Await

Key Learning Outcomes:

* Consuming REST APIs
* Handling network responses
* Managing asynchronous data retrieval

---

### 3. Promises

Files:

* `synchronous.js`
* `asynchronous.js`
* `promises.js`

Concepts practiced:

* Difference between synchronous and asynchronous execution
* Creating and consuming promises
* Promise states:

  * Pending
  * Fulfilled
  * Rejected
* Using `.then()`, `.catch()`, and `.finally()`

Key Learning Outcomes:

* Understanding JavaScript's asynchronous behavior
* Managing delayed operations
* Handling success and failure scenarios effectively

---

### 4. User Directory App

Files:

* `index.html`
* `style.css`
* `script.js`
* `README.md`

Description:

A simple web application that fetches and displays user information dynamically from an external API. The project demonstrates how asynchronous JavaScript can be used to retrieve and render data on a web page.

Features:

* Load user data from an API
* Dynamically render user cards
* Basic UI styling
* Error handling for failed requests
* DOM manipulation using JavaScript

Technologies Used:

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* Async/Await
