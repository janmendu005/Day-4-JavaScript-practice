# User Directory App

A simple JavaScript application that fetches user data from an API and displays it dynamically on the webpage.

## Features

- Fetch users from API
- Display user names
- Display user emails
- Async/Await implementation
- Fetch API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API

## API Used

https://jsonplaceholder.typicode.com/users

## Learning Outcomes

- Promises
- Async/Await
- Fetch API
- DOM Manipulation
- Event Handling
